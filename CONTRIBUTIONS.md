# Règles de contribution

Les paquets sont du code assisté de référence. Les membres utilisent leur identité GitHub réelle, sans changer les dates ni attribuer à une autre personne un travail réalisé. Un commit d’intégration peut mentionner « intégration du lot assisté et revue » ; une correction personnelle doit être décrite précisément.

Les fiches `contributions/M1.md` à `contributions/M7.md` doivent indiquer les fichiers compris, les adaptations, les résultats réels et les liens Jira. Le compte rendu vide est une préparation, pas une validation. Chaque revue est effectuée par le membre concerné depuis son compte.

Aucune branche ou invitation ne remplace une contribution.
